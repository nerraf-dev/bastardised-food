# Bastardised Food

Welcome to **Bastardised Food**! This repository is a fun and experimental collection of unconventional recipes, food hacks, and culinary creations that break the rules of traditional cooking. Whether you're a home cook looking to try something new, a foodie who loves to experiment, or just someone who enjoys a little chaos in the kitchen, this project is for you.

## 🍲 What is "Bastardised Food"?

"Bastardised food" refers to dishes that have been adapted, transformed, or completely reimagined from their originals—sometimes out of necessity, curiosity, or just for laughs. Here, you'll find recipes that:
- Put a creative spin on classic dishes
- Use unexpected ingredient substitutions
- Combine cuisines or techniques in wild ways
- Embrace the spirit of culinary improvisation

## 📂 Repository Structure

- `recipes/` — Main directory for all recipe files (markdown format).
- `images/` — Photos of finished dishes or in-progress shots.
- `docs/` — Additional documentation, guides, or resources.

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/nerraf-dev/bastardised-food.git
   cd bastardised-food
   ```
2. **Explore the recipes**  
   Browse the `recipes/` folder to find something that piques your interest.
3. **Try it out**  
   Recreate the dish at home and feel free to put your own twist on it!

## 📝 Contributing

Contributions are welcome! Want to add your own bastardised creation? Here’s how:
1. Fork the repo.
2. Add your recipe as a new markdown file in the `recipes/` directory.
3. (Optional) Add a photo in `images/` and link it in your recipe.
4. Open a pull request with a short description of your dish.

Please keep things light-hearted and respectful—this is about fun and creativity!
